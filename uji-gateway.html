Batas pengujian

JSON dicetak firmware gateway setelah CRC paket cocok. Halaman membuktikan paket sampai ke gateway dan browser; belum menguji WiFi, cloud, atau alarm fisik. Kode node saat ini mengganti DHT gagal dengan 27,5°C/65% dan tidak mengirim penanda sensor valid. Jadi angka dan status yang dilaporkan belum membuktikan semua sensor bekerja atau lokasi aman. Baterai, buzzer, dan LED tetap belum diuji.
